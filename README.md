# Shiva Sharma — Portfolio v2

White, responsive portfolio with:
- Motion and scroll reveal animations
- 3D hover tilt cards
- Animated 3D-style hero orb
- HTML/CSS/React/JavaScript/TypeScript/Git/GitHub logos
- Working LinkedIn, GitHub and email links
- JalNet / SAHAYAK featured as the major project in development

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Note
The portfolio currently uses Simple Icons CDN for technology logos, so an internet connection is needed for those icons to load.
